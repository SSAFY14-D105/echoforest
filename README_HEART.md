# ❤️ 손하트(Heart Gesture) 인식 모델 튜닝 보고서

## 1. 📊 데이터 수집 및 분석

`gesture-tuner.html` 도구를 사용하여 실제 제스처 데이터를 수집하고 분석했습니다.

### 1-1. 수집된 데이터 샘플 (CSV 요약)

| 케이스 | 제스처 종류 | 특징 (데이터 패턴) | 초기 인식 상태 |
| :--- | :--- | :--- | :--- |
| **Case A** | **양손 하트 (Full Heart)** | `m8_12`, `m12_16` 등 손가락 간 거리가 **0.1~0.2**로 매우 가까움. (클러스터 형성) | ❌ 실패 (조건 너무 엄격) |
| **Case B** | **엄지검지 하트 (Finger Heart)** | 검지-중지 거리(`m8_12`)가 **0.5 이상**으로 멀음. 나머지 손가락 펴짐. | ✅ 성공 |
| **Case C** | **세모 (Triangle)** | 검지가 곧게 펴져 있음. 손목(0)↔검지끝(8) 거리가 긺. | ⚠️ **오인식** (하트로 잘못 인식) |

### 1-2. 데이터 분석 인사이트
1.  **하트의 다양성**: 사용자는 손가락을 모을 수도(A), 펼 수도(B) 있다. 이를 별개로 구분하는 것은 비효율적이다.
2.  **세모 vs 하트**: 두 제스처 모두 엄지와 검지가 만나고(`Touching`), 아치형태(`Arch`)를 이룬다. 유일한 차이는 **"검지의 구부러짐(Bent)"** 정도이다.

## 2. 🛠️ 트러블 슈팅 (Troubleshooting)

### 문제 1: 양손 하트(Full Heart)가 인식되지 않음 
- **원인**: 초기 로직에서 "손가락 클러스터링(모임)" 조건을 필수(AND)로 넣었는데, 임계값(0.3)이 너무 엄격해서 손가락이 조금만 벌어져도 실패 처리됨.
- **해결**: 클러스터링 조건을 **제거**하고, "엄지와 검지가 만나는가"를 최우선 조건으로 변경하여 통합.
  ```javascript
  // Before: isTouching && isClustered
  // After: isTouching (나머지 손가락 상태는 무시)
  ```

### 문제 2: 세모(Triangle) 포즈가 하트로 오인식됨 ⚠️
- **원인**: 검지를 쫙 펴서 세모를 만들어도, 엄지-검지가 만나고(`Touching`) 검지가 안쪽 모양(`Curved`)이라 하트의 조건을 충족해버림.
- **시도 1 (좌표 비교)**: `Pip(6)` 좌표보다 `Tip(8)`이 아래에 있는지 확인 -> 손목 회전에 따라 오차가 커서 실패.
- **시도 2 (손목 거리 비교)**: 손목↔검지끝 거리가 짧아져야 한다고 가정 -> 손 크기 차이로 인해 기준 잡기 어려움.
- **해결 (검지 길이 비율)**: **검지의 "펴짐 비율"**을 계산하여 해결! 🎯
  - 검지를 펴면: 전체 길이(MCP→Tip)가 첫 마디(MCP→PIP)의 **약 2.2배**
  - 검지를 굽히면(하트): 전체 길이가 첫 마디의 **2.0배 미만**으로 줄어듦.

## 3. ✨ 최종 코드 로직 (Algorithm)

### 핵심 로직 요약
> **"엄지와 검지가 만나고(Touch), 안쪽으로 굽었으며(Arch), 확실히 접혀있어야(Bent) 한다."**

### 적용된 코드 (`HeartGesture.js`)

```javascript
/* 1. 접점 체크 (Touching): 엄지와 검지가 만나는가? */
const isTouching = thumbDist < 0.25 && indexDist < 0.25;

/* 2. 모양 체크 (Arch): 검지가 안쪽을 향하는가? */
const isCurvedL = handL[8].x > handL[5].x; 
const isCurvedR = handR[8].x < handR[5].x; 

/* 3. 굽힘 체크 (Bent) - 세모 방지 핵심 로직! ⭐ */
// 검지 전체 길이(5->8)가 첫 마디(5->6)의 2배보다 작아야 함
// 펴져 있으면(세모) 비율이 2.1~2.2가 됨
const indexLenL = distance(handL[5], handL[8]); // 전체 길이
const indexBaseL = distance(handL[5], handL[6]); // 첫 마디 길이
const isBentL = indexLenL < indexBaseL * 2.0;

const indexLenR = distance(handR[5], handR[8]);
const indexBaseR = distance(handR[5], handR[6]);
const isBentR = indexLenR < indexBaseR * 2.0;

/* 최종 판정 */
if (isTouching && isCurvedL && isCurvedR && isBentL && isBentR) {
    return { label: '하트 ❤️' };
}
```
