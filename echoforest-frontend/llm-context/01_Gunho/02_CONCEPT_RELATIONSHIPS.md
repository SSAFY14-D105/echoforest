# 🦅 Cursed Echoes: 기술 관계도 가이드 (Ecological Guide)

사용자님의 **'참새 학습법'**에 맞춰, 각 기술을 하나의 생명체로 보고 그들이 사는 환경, 친구(동료), 천적, 그리고 유사한 종들과의 관계를 중심으로 정리했습니다.

---

## 🗺️ 전체 여정: 5단계 관계망 (Pivoted)

1.  **[채집]** 유저의 입(소리) -> **Web Speech API** (소리를 글자로)
2.  **[가공]** 글자 -> **FastAPI (AI 서버)** (글자를 감정으로)
3.  **[보고]** 내 브라우저 -> **WebSocket** (결과를 게임 서버로)
4.  **[전파]** 게임 서버 -> **다른 유저들** (사건을 모두에게)
5.  **[표현]** 서버 메시지 -> **React & Phaser** (현상을 눈으로)

---

## 🌿 1단계: 소리를 글자로 (Speech to Text)

### 🐦 오브젝트: Web Speech API
*   **서식지 (환경)**: 모든 브라우저(Chrome 등)의 내부. 따로 설치할 필요 없는 '자생종'입니다.
*   **습성**: 유저가 마이크 권한을 주면, 소리를 실시간으로 듣고 적절한 텍스트로 바꿔서 뱉어냅니다.
*   **동료 (Allies)**: `navigator.mediaDevices` (마이크 하드웨어에 접근할 수 있게 도와주는 친구).
*   **천적 (Enemies)**: **소음**과 **권한 거부**. 유저가 "마이크 사용 안 함"을 누르면 굶어 죽습니다.
*   **사촌 (Similiar Species)**: **Whisper API**. 서버 성능을 빌려 쓰는 더 똑똑하고 비싼 사촌입니다. 브라우저 내장 API는 조금 덜 똑똑하지만 빠르고 무료입니다.

---

## 🧠 2단계: 지능의 이원화 (Dual Intelligence)

우리 게임은 효율을 위해 지능(AI)을 두 곳에 나누어 배치했습니다.

### 🐦 오브젝트: FastAPI (원격 지능 - STT/감정)
*   **서식지 (환경)**: 멀리 떨어진 별도의 전용 서버. **Miniforge** 기반의 **`ai-server`** 환경.
*   **습성**: 텍스트를 정밀하게 분석하여 '욕설'인지를 판별합니다.
*   **일하는 방식**: **HTTP Post (택배)**. 프론트가 보낸 텍스트를 분석하여 결과를 다시 보내줍니다.

### 🐦 오브젝트: MediaPipe (현지 지능 - 모션)
*   **서식지 (환경)**: 유저의 브라우저 내부. **WebGPU**와 **Web Worker**의 도움을 받습니다.
*   **습성**: 카메라 영상을 뚫어지게 보며 관절의 위치를 실시간으로 추적합니다.
*   **일하는 방식**: **로컬 연산**. 영상 데이터를 서버로 보낼 필요 없이 내 컴퓨터에서 즉시 계산합니다.

---

## 📡 3단계: 보고와 전파 (The Reporting Chain)

### 🐦 흐름: AI 결과들의 집합
*   **원격 결과**: FastAPI로부터 받은 '감정 분석 결과'
*   **현지 결과**: MediaPipe로부터 얻은 '포즈 인식 결과'
*   **행동**: 프론트엔드는 이 두 결과물을 잘 모아서, **WebSocket**이라는 실시간 빨대를 통해 백엔드(Spring)에게 **"이 유저가 이런 행동을 했어요!"**라고 최종 보고합니다.

---

### 🐦 오브젝트: WebSocket (웹소켓)
*   **서식지 (환경)**: 브라우저와 게임 서버(Spring) 사이의 **'끊기지 않는 빨대'**.
*   **습성**: 한 번 연결되면 누구든 원할 때 말을 걸 수 있습니다. '전화기'와 비슷합니다.
*   **비교 (대조)**: **HTTP (일반 웹 요청)**. 이건 '편지'입니다. 반면, 웹소켓은 서로 실시간으로 대화합니다.
*   **동료 (Allies)**: **JSON**. 대화할 때 사용하는 '공용 언어(데이터 형식)'입니다.

---

## ⚙️ 4단계: 사령탑 (Headquarters)

### 🐦 오브젝트: 백엔드 (Spring Boot)
*   **서식지 (환경)**: 멀리 떨어진 강력한 서버 컴퓨터.
*   **습성**: 모든 유저의 상태를 관리하고, 판결 결과에 따라 "너 독 걸려!"라고 최종 결정을 내립니다.
*   **천적 (Enemies)**: **동시 접속자 폭주**. 

---

## 🎨 5단계: 현상의 시각화 (Visualization)

### 🐦 오브젝트: React & Phaser 3 (프론트엔드 엔진)
*   **서식지 (환경)**: 유저의 모니터 화면.
*   **습성**: 서버에서 보낸 메시지를 받으면, 즉시 캐릭터 위에 효과를 그리거나 조작을 반전시킵니다.
