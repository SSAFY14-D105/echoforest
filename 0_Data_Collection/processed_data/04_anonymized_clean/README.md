# 04_anonymized_clean — 수집 STT 코퍼스 + 수동 8라벨 (대표본)

게임 유튜브 STT를 정제·익명화(`[유저]`)·고급정제까지 거친 **최종 수집 코퍼스 15,281문장**에, 키워드 기반 **수동 8라벨**을 부여한 파일.

- `final_dataset.tsv` — `sentence` + 8라벨(abuse · hate · clean · blame · anger · frustration · praise · order)

> 수집 파이프라인의 마지막 텍스트 산출물 = 우리가 실제로 모은 게임 채팅 코퍼스. 8라벨 체계는 미채택입니다. [상위 README](../README.md).
