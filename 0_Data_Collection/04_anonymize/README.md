# 04_anonymize — 개인지칭(닉네임) 토큰 제거

`04_text_anonymize.py`가 `../03_clean` 문장에서 **개인지칭(등록 닉네임 / 고유명사+호칭)의 토큰만 제거**합니다 — 행을 통째로 삭제하지도, `[유저]`로 치환하지도 않고 **이름 + 동반 호칭·조사만 빼고 문장은 유지**. → `final_dataset.tsv` (`source` 칼럼 보존).

**왜 행 삭제가 아니라 토큰 제거?** 닉네임 든 문장은 대개 "기우자 대가리로 올라가" 같은 게임 오더 = unSmile이 욕설로 오탐하는 **hard-negative(욕설처럼 보이는 clean)**. 행을 통째로 지우면 모델이 "오더≠욕설"을 배울 핵심 예시를 잃는다 → 이름만 빼고 보존한다.
→ `기우자 대가리로 올라가` → `대가리로 올라가` (privacy 해결 + `[유저]` 토큰도 안 씀 + hard-negative 보존)

Kiwi NNP 기반이되, 외래어·게임명(나이스·캐리·피코파크 등) 과제거는 방지(닉네임+호칭만). 영상별 화자명을 `CUSTOM_USERS`에 추가하면 탐지율↑. 닉네임만 남아 비워진 행은 제외. 감사 도구: [`_audit_anonymize.py`](_audit_anonymize.py).
