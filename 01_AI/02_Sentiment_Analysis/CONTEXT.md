# 🧠 감정 분석 Context

## 1. 왜 감정 분석이 필요한가?

### 게임 컨셉
**"메아리의 숲"**은 플레이어 간 분노(욕설)를 AI로 감지하고, 강제로 애정 표현을 요구하는 게임입니다.

### 핵심 기능
| 기능 | 설명 | 필요 기술 |
|------|------|----------|
| **긍정 키워드 감지** | "뽀뽀", "사랑해" → 스킬 발동 | 단순 문자열 매칭 |
| **부정 문맥 감지** | 욕설, 비꼼 → 페널티 | 🔴 NLP 문맥 분석 필요 |

### 왜 패턴 매칭으로 부족한가?
```
❌ 단순 매칭의 한계:
   - "야 진짜 잘하네~" (비꼼) → 텍스트만 보면 긍정
   - "하... 왜 이래" (짜증) → 욕설 없지만 부정적
   
✅ 문맥 분석 필요:
   - 전체 문장의 뉘앙스 파악
   - 한국어 특유의 표현 이해
```

## 2. 기술적 제약 조건

### 브라우저 환경 제약
| 항목 | 제약 | 이유 |
|------|------|------|
| **메모리** | ~200MB 이하 | 게임 + 모션 인식 고려 |
| **레이턴시** | ~100ms 이하 | 실시간 게임 반응성 |
| **실행 환경** | 브라우저 (WebGPU) | 서버 부담 분산 |

### 왜 브라우저에서?
```
1000명 동시 접속 시:
- 서버 처리: 서버 1대가 AI 연산 → 터짐 💥
- 브라우저 처리: 각 사용자 PC가 분담 → 서버 부담 0 ✅
```

---

## 3. 평가 목표

### 정량적 지표
1. **정확도 (Accuracy)**: 부정/긍정 분류 정확도
2. **F1 Score**: 불균형 데이터셋 고려
3. **레이턴시 (ms)**: 추론 시간
4. **메모리 (MB)**: 모델 로드 후 VRAM/RAM 사용량

### 정성적 평가
- 한국어 비속어 인식률
- 비꼼/냉소 감지 능력
- 게임 맥락 특화 표현 이해

## 5. 실험 단계

```
Phase 1: 기본 성능 측정 (현재)
   └─ 각 모델의 기본 인식률, 레이턴시 측정

Phase 2: 한국어 테스트
   └─ 한국어 감정 데이터셋으로 정확도 비교

Phase 3: 게임 데이터 수집
   └─ 실제 게임 욕설/비꼼 표현 수집

Phase 4: Fine-tuning
   └─ 최종 선택 모델 파인튜닝
```
