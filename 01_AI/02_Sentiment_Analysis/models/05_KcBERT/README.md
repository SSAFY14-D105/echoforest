# KcBERT Sentiment 테스트

한국어 댓글 데이터로 학습된 BERT 모델입니다.

## 모델 정보

| 항목 | 내용 |
|------|------|
| **원본 모델** | beomi/kcbert-base |
| **기반** | BERT (한국어 댓글 특화) |
| **학습 데이터** | 네이버 뉴스 댓글 |
| **예상 크기** | ~400MB (base), ~100MB (양자화) |
| **한국어** | ✅ 댓글/비속어에 강함 |

## 특징
- 한국어 온라인 댓글로 학습 → 비속어, 신조어에 강함
- 게임 채팅 맥락과 유사!
- 다소 큼 (base 모델)
