# UnSmile (스마일게이트 혐오 발언 탐지)

스마일게이트에서 개발한 한국어 혐오 발언 탐지 모델입니다.

## 모델 정보

| 항목 | 내용 |
|------|------|
| **Hugging Face** | `smilegate-ai/kor_unsmile` |
| **개발사** | 스마일게이트 AI |
| **학습 데이터** | 한국어 혐오 발언 데이터셋 |
| **출력** | clean / 악플/욕설 / 기타 카테고리 |

## 벤치마크 결과

| 지표 | 값 |
|------|-----|
| 정확도 | 50.0% |
| 레이턴시 | **7.9ms** ⚡ 최저 |
| 로드시간 | 1.7s |

## 특징

- **혐오 발언 특화**: 욕설, 비하, 혐오 표현 탐지
- **한국어 특화**: 한국어 온라인 댓글 데이터로 학습
- **빠른 속도**: 벤치마크에서 가장 빠른 레이턴시!
- **게임 적합**: 채팅 욕설 필터링에 적합

## 출력 카테고리

```
- clean: 정상 발언
- 악플/욕설: 욕설, 비난
- 여성/가족: 성차별적 표현
- 남성: 남성 혐오 표현
- 성소수자: 성소수자 혐오
- 인종/국적: 인종차별
- 연령: 연령 차별
- 지역: 지역 비하
- 종교: 종교 비하
- 기타 혐오: 기타
```

## 사용 예시

```python
from transformers import pipeline

classifier = pipeline("text-classification", model="smilegate-ai/kor_unsmile")
result = classifier("정말 좋은 하루예요!")
print(result)  # [{'label': 'clean', 'score': 0.95}]
```

## 게임에 적합한 이유

1. **욕설 감지에 특화** → 게임 채팅 필터링
2. **빠른 속도** → 실시간 감지 가능
3. **한국어 원어민 수준** → 신조어, 변형 욕설도 감지
