## 왜 혐오 발언 탐지?

감정 분석(Sentiment)은 긍정/부정을 구분하지만,
혐오 발언 탐지(Hate Speech)는 **"독성 발언"**에 특화됨:

```
감정 분석: "야 진짜 잘하네~" → NEGATIVE (비꼼)
혐오 탐지: "야 ㅅㅂ 뭐하냐" → TOXIC (독성) ⭐ 더 정확
```

## 게임에 더 적합할 수 있는 이유

1. 욕설 데이터로 학습 → 게임 채팅과 유사
2. 비꼼/냉소도 독성으로 분류 가능
3. 긍정 키워드는 별도 JS 매칭으로 처리
