## 시스템 개요

### 목표
- **긍정 키워드** (뽀뽀, 사랑해) → 즉시 스킬 발동
- **부정 발언** (욕설, 비꼼) → 일정 딜레이 후 저주 발동

### 아키텍처

```
[사용자 음성]
     ↓
[Web Speech API (STT)]
     ↓
┌────────────────┬────────────────┐
│  긍정 키워드     │   부정 발언     │
│  (JS 매칭)      │  (AI 분석)     │
│                │                │
│  즉시 반응!     │  딜레이 후 반응  │
│  (~50ms)       │  (~5-10초)     │
└────────────────┴────────────────┘
```

## 긍정/부정 처리 분리

### 긍정 키워드 (스킬) - Push-to-Talk

| 항목 | 값 |
|------|-----|
| 입력 방식 | 버튼 누르고 말하기 |
| 처리 | 중간 결과에서 JS 키워드 매칭 |
| 레이턴시 목표 | < 50ms |
| 예시 | "뽀뽀", "사랑해", "최고야" |

```javascript
// 중간 결과에서 즉시 감지
recognition.onresult = (event) => {
  const interim = event.results[event.resultIndex][0].transcript;
  if (interim.includes("뽀뽀")) {
    triggerSkill();  // VAD 대기 없이 즉시!
  }
};
```

### 부정 발언 (저주) - 상시 감지

| 항목 | 값 |
|------|-----|
| 입력 방식 | 상시 녹음 (continuous) |
| 처리 | VAD 청킹 → AI 감정 분석 |
| 레이턴시 | 5~10초 OK (의도적 딜레이) |
| 예시 | "야 뭐하냐", "씨발", 비꼼 표현 |

## 데이터 수집 전략

### 왜 기존 데이터셋이 안 맞는가?

| 기존 데이터 | 문제점 |
|------------|--------|
| 텍스트 채팅 | "ㅅㅂ", "ㄹㅇ" 등 초성체 → STT에 없음 |
| 영화 리뷰 | 게임 맥락과 다름 |
| 기존 모델 | 욕설 학습 안 됨 (윤리적 이유) |

### 해결책: 유튜브 게임 VOD 수집

```
1. 협력 게임 유튜버 VOD 선정
2. yt-dlp로 음성만 다운로드
3. Whisper로 STT 변환
4. 반자동 라벨링 (UnSmile 1차 → 수동 검토)
5. Fine-tuning
```

### 음성 다운로드 명령어

```bash
# 음성만 추출 (영상 없이!)
yt-dlp -x --audio-format mp3 --audio-quality 0 "VIDEO_URL"

# 여러 영상 일괄 다운로드
yt-dlp -x --audio-format mp3 -a urls.txt
```

### 용량 예측

| 항목 | 예상 값 |
|------|---------|
| 수집 시간 | 50~100시간 |
| 음성 용량 | ~5GB (MP3) |
| 문장 수 | ~50,000개 |
| 실제 학습 데이터 | ~5,000~10,000개 |

## 📊 평가 지표 설명 (발표용)

### Confusion Matrix (혼동 행렬)

```
                    예측
                 Positive  Negative
실제  Positive     TP        FN
      Negative     FP        TN
```

| 용어 | 의미 | 예시 |
|------|------|------|
| **TP** (True Positive) | 부정을 부정으로 맞춤 | "씨발" → 부정 ✅ |
| **TN** (True Negative) | 긍정을 긍정으로 맞춤 | "사랑해" → 긍정 ✅ |
| **FP** (False Positive) | 긍정을 부정으로 틀림 | "사랑해" → 부정 ❌ |
| **FN** (False Negative) | 부정을 긍정으로 틀림 | "씨발" → 긍정 ❌ |

### 평가 지표 공식

| 지표 | 공식 | 의미 |
|------|------|------|
| **Accuracy** | (TP + TN) / 전체 | 전체 정답률 |
| **Precision** | TP / (TP + FP) | 부정이라고 한 것 중 진짜 부정 비율 |
| **Recall** | TP / (TP + FN) | 실제 부정 중 찾아낸 비율 |
| **F1 Score** | 2 × (P × R) / (P + R) | Precision과 Recall의 조화 평균 |

### 게임에서 중요한 지표

| 상황 | 중요 지표 | 이유 |
|------|----------|------|
| **저주 (부정)** | Recall ↑ | 욕설 놓치면 안 됨! |
| **스킬 (긍정)** | Precision ↑ | 잘못 발동하면 안 됨! |

### 예시 계산

```
테스트 결과:
- TP = 4 (욕설 4개 맞춤)
- TN = 4 (긍정 4개 맞춤)
- FP = 1 (긍정을 욕설로 틀림)
- FN = 1 (욕설을 긍정으로 틀림)

Accuracy  = (4 + 4) / 10 = 80%
Precision = 4 / (4 + 1) = 80%
Recall    = 4 / (4 + 1) = 80%
F1 Score  = 2 × (0.8 × 0.8) / (0.8 + 0.8) = 80%
```

## 트러블슈팅

### Q1: transformers 업그레이드 시 충돌?

**A**: 이미 faster-whisper와 충돌 경고 있음. 감정 분석에는 영향 없음.

```bash
# 필요시
pip install --upgrade transformers
```

### Q2: XLM-RoBERTa 에러?

**A**: 벤치마크에서 제외함.

```python
# 제외됨
# ("XLM-RoBERTa", "cardiffnlp/...")
```

### Q3: 정확도 51% vs 49% 왜 이렇게 비슷?

**A**: 학습 데이터 ≠ 테스트 데이터 도메인.
- 해결: 게임 음성 데이터로 Fine-tuning

### Q4: 모델 캐시 어디?

**A**: `C:\Users\{사용자}\.cache\huggingface\`
- 한 번 다운로드하면 재사용됨

### Q5: VAD 지연 문제?

**A**: 
- 긍정 키워드: 중간 결과에서 JS 매칭 (VAD 대기 없음)
- 부정 발언: VAD 청킹 후 AI 분석 (딜레이 OK)

### Q6: 유튜브 영상 용량?

**A**: `yt-dlp -x` 옵션으로 음성만 추출 (1/100 용량)
