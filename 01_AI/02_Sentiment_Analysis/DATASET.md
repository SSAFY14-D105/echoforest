# 📊 키워드/문장 데이터셋 문서

## 개요

게임 음성 분석을 위한 테스트 문장 데이터셋입니다.  
STT 출력 스타일에 맞춰 작성되었습니다 (초성체 제외).

## 카테고리별 예시

### 긍정 (스킬 발동)
```
사랑해, 뽀뽀, 최고야, 잘했어, 고마워
"야 진짜 너무 잘했어"
"와 진짜 대박이다 너무 잘했어 진짜로"
```

### 부정 (저주 발동)  
```
씨발, 꺼져, 닥쳐, 짜증나, 못해
"야 씨발 뭐하냐"
"야 씨발 왜 이래 진짜 못하네 아"
```

### 중립 (무시)
```
일로 와, 점프해, 하나 둘 셋, 기다려
"같이 점프해야 해"
"야 빨리 일로 와 시간 없어"
```

## 고려해야 할 점

### ✅ 현재 해결된 것
- STT 출력 스타일 (초성체 제외)
- 다양한 문장 길이
- 게임 협력 상황 문장

### ⚠️ 추가 고려 필요
1. **비꼼/냉소**: "야 잘하네" → 맥락에 따라 다름
2. **애매한 명령**: "빨리 해" → 짜증? 독촉?
3. **질문형**: "뭐야?" → 중립? 짜증?
4. **사투리/방언**: 지역별 표현 차이
5. **게임 용어**: 게임별 특수 표현

## 데이터 추가 방법

`keywords.json`에 직접 추가:

```json
{
  "positive_sentences": [
    "새 문장 추가",
    ...
  ],
  "negative_sentences": [...],
  "neutral_sentences": [...]
}
```

벤치마크 실행 시 자동 반영됩니다.
