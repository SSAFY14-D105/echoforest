# 🎙️ 음성 인식(STT) 기술 심층 분석 보고서

## 1. 🤔 "왜 로컬이 서버보다 느린가?" (The Latency Paradox)
"내 컴퓨터에서 바로 돌리는데(Local), 왜 바다 건너 서버를 갔다 오는(Server) 것보다 느릴까?"

### A. Local Whisper (Browser-based)의 병목
*   **실행 환경의 한계**: `Transformers.js`는 브라우저의 **WebAssembly (WASM)** 위에서 돌아갑니다. 이는 Python이나 C++처럼 하드웨어(GPU)를 직접 100% 활용하지 못합니다.
*   **연산 부하**: 음성 인식은 거대한 행렬 연산입니다. 일반 노트북 CPU로 브라우저 탭 하나에서 이를 처리하려면 과부하가 걸립니다. (1초 분량 오디오 처리에 1.5초가 걸리면, 실시간 처리는 불가능합니다.)
*   **결론**: "거리는 가깝지만(0km), 자전거(CPU)로 배달하는 격"입니다.

### B. Web Speech API (Google Server)의 속도
*   **압도적인 자원**: 구글 클라우드는 일반 컴퓨터보다 수천 배 빠른 **TPU(Tensor Processing Unit)** 라는 전용 AI 반도체로 순식간에 추론을 끝냅니다.
*   **최적화**: 음성 데이터 전송(Network)은 약 0.1초밖에 안 걸립니다. 추론이 0.01초 만에 끝나기 때문에 합쳐도 0.2초 이내입니다.
*   **결론**: "거리는 멀지만(왕복 20,000km), 초음속 제트기(TPU)로 배달하는 격"입니다. 훨씬 빠릅니다.

## 2. 🤖 "이게 AI 프로젝트라고 할 수 있나?"
Web Speech API 사용 시 프로젝트 심사에서 받을 수 있는 질문과 대안입니다.

### Q. "API 쓴 거면 AI 구현이 아니라 그냥 붙여넣기 아닌가요?" (치명적)
*   **Web Speech API**는 편하지만, "우리가 모델을 튜닝했다"거나 "최신 기술을 도입했다"고 말하기 어렵습니다. (구글 기술이지 우리 기술이 아님).

### 💡 대안: "자체 구축 AI 서버" (Self-Hosted Server)
프로젝트 점수(기술 점수)를 챙기면서 속도도 잡으려면 **"Python FastAPI 서버 + Faster-Whisper"** 조합이 정답일 수 있습니다.

| 구분 | 1. Local Browser (v1) | 2. Google API (v2) | 3. **Python Server (추천)** |
| :--- | :--- | :--- | :--- |
| **속도** | 느림 (1.7초) | 매우 빠름 (0.3초) | **빠름 (0.5초, GPU 사용 시)** |
| **AI 기여도** | 높음 | 낮음 (API 호출) | **매우 높음 (서버 구축/튜닝)** |
| **비용** | 무료 (사용자 CPU) | 무료 (Chrome 한정) | **서버 GPU 비용 발생** |
| **구현 난이도**| 높음 | 매우 낮음 | **중간 (백엔드 필요)** |

### � 전략 제안
1.  **프로토타입(현재)**: 일단 **Web Speech API**로 게임의 재미(기획)를 먼저 검증합니다.
2.  **본 개발(Next)**: **Python(FastAPI) + Faster-Whisper** 서버를 띄워서, 구글 API를 대체합니다.
    *   이렇게 하면 **"우리는 Latency 문제 해결을 위해 경량화된 Faster-Whisper 모델을 GPU 서버에 직접 배포하여 0.5초 이내 응답속도를 달성했습니다"** 라는 **완벽한 포트폴리오 스토리**가 나옵니다.

## 3. 📖 주요 기술 용어

*   **WASM (WebAssembly)**: 브라우저에서 고성능 연산을 하기 위한 기술. 빠르지만 네이티브 앱보다는 느림.
*   **TPU/GPU**: AI 연산 전용 하드웨어. 구글 서버엔 이게 깔려있음.
*   **Inference (추론)**: 학습된 AI 모델이 실전에서 "이 소리는 '사랑해'야"라고 맞추는 과정.
*   **Interim Results (중간 결과)**: 문장이 완성되기 전에 AI가 "지금까지 들은 건 이건데..." 하고 던져주는 예측값. 반응 속도 핵심.
