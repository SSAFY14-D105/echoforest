## 1. 📅 기술 검증 여정 (Timeline)

### 🛑 1차 시도: Local Whisper (Client-side AI)
*   **접근 방식**: 사용자의 브라우저에 AI 모델(Whisper-tiny)을 다운로드 받아 직접 돌리는 방식.
*   **의도**: "서버 비용 0원, 네트워크 지연 0ms"를 꿈꾸며 시작.
*   **결과**: **실패 (Latency 1.7초)**.
*   **원인**:
    *   브라우저상에서 무거운 AI 연산을 하느라 정작 "추론" 속도가 느림.
    *   PC 사양을 엄청나게 탐.
    *   결정적으로 게임(피코파크 류)용으로는 1초의 딜레이도 치명적임.

### ✅ 2차 시도: Web Speech API (Chrome Built-in)
*   **접근 방식**: 크롬 브라우저에 내장된 `webkitSpeechRecognition` 엔진 사용.
*   **특징**: 구글의 강력한 클라우드 서버 + 브라우저 내부 C++ 최적화 엔진 사용.
*   **결과**: **성공 (매우 빠름)**.
    *   모델 다운로드 필요 없음.
    *   한국어 인식률 매우 높음.

### ⚡ 3차 최적화: 반응 속도 '0'의 비밀
*   **문제**: 빨라지긴 했으나 미묘한 **"괴리감(딜레이)"** 발생.
*   **원인 (VAD 문제)**: 기계는 사용자가 "말을 다 했나?"를 판단하기 위해 침묵을 0.5초 정도 기다림. 이 0.5초가 딜레이의 주범.
*   **해결 (Interim Results)**:
    *   "말이 끝날 때까지 기다리지 마! 중간에라도 단어가 들리면 바로 쏴!"
    *   `interimResults = true` 설정을 통해 **말하는 도중에** 버프가 발동되도록 수정.
    *   **결과**: 체감 레이턴시 거의 0에 가까움.

## 2. 📖 용어 설명 (Glossary)

팀원들이 물어볼 법한 용어들입니다.

| 용어 | 뜻 | 쉬운 설명 |
| :--- | :--- | :--- |
| **STT** (Speech-to-Text) | 음성을 텍스트로 변환 | 그냥 "받아쓰기" 기술. |
| **VAD** (Voice Activity Detection) | 음성 활동 감지 | "지금 말하는 중인가? 아니면 숨 쉬는 소리인가?"를 구분하는 센서. |
| **Latency** (레이턴시) | 지연 시간 | 내가 "점프"라고 뱉은 순간부터 실제 캐릭터가 뛸 때까지 걸린 시간. |
| **Silence Timeout** | 침묵 대기 시간 | VAD가 "어? 소리 안 나네? 말 끝났나보다"라고 확정 짓기 위해 기다리는 눈치 보는 시간. (보통 0.5초) |
| **Interim Results** | 중간 결과 | "안녕하세요"를 말할 때 "안.. 안녕.. 안녕하.." 이렇게 실시간으로 들어오는 미완성 텍스트. 이걸 쓰면 속도가 엄청 빨라짐. |

## 3. 💻 코드 설명 (Code Walkthrough)

`speech_api.js` 파일의 핵심 부분입니다.

### 핵심 설정 끄고 켜기
```javascript
const recognition = new webkitSpeechRecognition();

// 1. 한국어 설정
recognition.lang = 'ko-KR'; 

// 2. 계속 듣기 모드 (false면 한마디 하고 꺼짐)
recognition.continuous = true; 

// 3. ✨ 마법의 설정 (이게 false면 느려짐)
// true: "안.. 안녕.." 처럼 중간 과정도 계속 받음 (빠름)
// false: 문장이 완벽히 끝날 때까지 기다렸다가 한 번에 줌 (느림)
recognition.interimResults = true; 
```
