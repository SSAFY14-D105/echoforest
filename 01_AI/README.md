# 🌲 EchoForest Frontend

4인 협동 멀티플레이어 게임 **"메아리의 숲"**의 프론트엔드입니다.

## 🚀 Quick Start

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

## 🛠️ Tech Stack

- **React + TypeScript + Vite**
- **Phaser 3** (Matter.js 물리 엔진)
- **Zustand** (상태 관리)
- **LiveKit** (실시간 통신)
- **Tailwind CSS + shadcn/ui**

## 📂 Project Structure

```
echoforest-frontend/
├── src/
│   ├── components/    # React 컴포넌트
│   ├── game/          # Phaser 게임 로직
│   ├── stores/        # Zustand 스토어
│   └── utils/         # 유틸리티 함수
├── public/            # 정적 파일
└── ...
```
