# 💖 긍정어 시스템 (Positive Word System)

저주를 해제하거나 게임에 이로운 효과를 주는 시스템입니다.
정확한 인식을 위해 음성 감지(VAD)가 아닌 **버튼을 누르고 말하는 방식**을 사용합니다.

## 1. 🗣️ 발동 방식: Push to Talk (PTT)
- **이유**: 게임 소음이나 배경 잡음으로 인한 오인식을 방지하고, 명확한 의사 표현을 구분하기 위함 (VAD 한계 보완).
- **조작**: 특정 키(예: `Space` 또는 `V`)를 누른 상태에서 말을 해야만 인식이 됨.
- **분석**: PTT로 입력된 음성은 텍스트로 변환(STT) 후 긍정어 목록과 대조.

## 2. 긍정어 감지 (Detection)
- **대상 단어**: "고마워", "잘했어", "사랑해", "파이팅", "미안해", "할 수 있어" 등.
- **기술**: Google STT 또는 Local Whisper (빠른 응답 속도 중요).

## 3. 효과 (Effect)
- **저주 해제 (Cleansing)**:
    - 현재 팀원(혹은 본인)에게 걸린 저주를 즉시 제거.
    - 예: "@@아 미안해!" 라고 외치면 @@에게 걸린 저주 해제.
- **공통 스택 감소**:
    - 저주가 발동하기 전이라면, 쌓여있는 '공통 저주 스택'을 1단계 낮춤.

## 4. 피드백 UI
- **시각 효과**: 캐릭터 머리 위에서 하트 파티클 폭발, 밝은 아우라 생성.
- **청각 효과**: 띠링~ 하는 맑은 효과음.
