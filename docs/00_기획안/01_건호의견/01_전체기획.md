# 📄 전체 기획 (Overall Plan)

프로젝트 **'메아리의 숲(가제)'**의 전체적인 페이지 흐름과 핵심 기능을 정의합니다.

## 1. 🔑 인증 (Authentication)
- **회원가입**: 아이디(중복확인), 비밀번호, 닉네임 입력.
- **로그인**: 아이디/비밀번호 검증, JWT 토큰 발급.
- **닉네임**: 게임 내 식별자.

## 2. 🏠 로비 (Lobby)
- **방 만들기**: 제목 설정, 방 생성.
- **방 입장하기**: 6자리 초대 코드 입력.
- **캐릭터**: 기본 픽셀 개구리 캐릭터 할당.

## 3. ⏳ 대기실 (Waiting Room)
- **입장 확인**: 최대 4명 슬롯.
- **화상 테스트**: LiveKit 연결 확인 (카메라/마이크).
- **게임 시작**: 방장 권한으로 시작.

## 4. 🎮 인게임 핵심 메커니즘 (Core Mechanics)

### 4.1. 하이브리드 UI 레이아웃
- **메인**: Phaser 3 기반의 횡스크롤 플랫포머 게임.
- **사이드바**: 우측에 4인의 화상(LiveKit) 화면 배치, 실시간 소통 강조.

### 4.2. 🤖 AI & 소통 시스템 (차별점)
게임 내 소통이 게임 난이도와 진행에 직접적인 영향을 줍니다.

*   **😈 저주 시스템 (상시 감지)**
    *   **작동**: 3~5초 단위로 대화를 끊어서(Chunking) **Unsmile 모델**로 욕설/비속어 분석.
    *   **공통 스택**: 욕설 적발 시 팀 공유 스택(1~3단계)이 쌓임.
    *   **랜덤 처벌**: 스택 MAX 시 **팀원 중 한 명에게 랜덤으로 저주** 발동 (남 탓 유도).
    *   **침묵 패널티**: 욕을 안 하려고 말을 안 하면(Silence), 캐릭터가 점점 느려지다가 멈춤 (소통 강제).
    *   [상세 내용 보기](./02_저주시스템.md)

*   **💖 긍정어 시스템 (Push to Talk)**
    *   **작동**: VAD 오인식 방지를 위해 **키를 누르고 말하는(PTT)** 방식 사용.
    *   **효과**: "고마워", "사랑해" 등 긍정어 인식 시 저주 해제 또는 스택 감소.
    *   [상세 내용 보기](./03_긍정어시스템.md)
