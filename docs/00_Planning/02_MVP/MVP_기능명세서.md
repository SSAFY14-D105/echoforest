# 🚀 MVP (Minimum Viable Product) 기능 명세서

이 문서는 프로젝트 런칭을 위해 **"반드시 있어야 하는 기능"**만을 정의합니다.
이 목록에 없는 기능은 **'추후 개선(Backlog)'**으로 미루어, 핵심 기능의 완성도를 높이는 데 집중합니다.

---

## 1. 🔑 인증 (Authentication)
사용자 식별을 위한 최소한의 기능입니다.

- [ ] **회원가입**: 아이디(중복확인), 비밀번호, 닉네임 입력.
- [ ] **로그인**: 아이디/비밀번호 검증 및 JWT 토큰 발급.
- [ ] **닉네임 표시**: 게임 내에서 사용할 닉네임 저장.
- *(제외)*: 소셜 로그인, 비밀번호 찾기, 이메일 인증 (MVP 제외).

## 2. 🏠 로비 (Lobby)
게임 방을 만들고 들어가는 진입점입니다.

- [ ] **방 만들기**: 방 제목만 입력하여 생성 (비밀번호 등 복잡한 설정 제외).
- [ ] **방 입장하기**: **6자리 입장 코드**를 입력하여 접속 (가장 빠르고 확실한 방법).
- [ ] **방 리스트 (Optional)**: 공개된 방 목록 표시 (우선순위 낮음).

## 3. ⏳ 대기실 (Waiting Room)
게임 시작 전 동기화를 맞추는 단계입니다.

- [ ] **플레이어 슬롯**: 최대 4명 입장 확인.
- [ ] **화상 연결 확인**: 입장 시 LiveKit 자동 연결 (내 얼굴/목소리 확인).
- [ ] **게임 시작**: 방장(Host)만 '시작' 버튼 클릭 가능. 
- *(제외)*: 캐릭터 꾸미기, 상세 설정 (MVP 제외, 기본 캐릭터 랜덤/순서대로 할당).

## 4. 🎮 인게임 & 화상 (Game + LiveKit) - **핵심(Core)**
프로젝트의 알파이자 오메가입니다.

- [ ] **맵 & 카메라**: 3000px 횡스크롤 맵, 플레이어 위치에 따른 카메라 이동.
- [ ] **멀티플레이 동기화**:
    - 다른 플레이어의 이동(좌우), 점프 동작이 0.1초 내외로 동기화.
    - 접속 종료 시 캐릭터 사라짐 처리.
- [ ] **화상 사이드바**: 우측에 4명 캠 화면 표시 (게임 화면 안 가리게 배치).
- [ ] **음성 채팅**: 상시 대화 가능 (Discord 같은 느낌).

## 5. 🤖 AI 기능 (One Core Feature)
복잡한 기능을 다 넣기보다, **가장 임팩트 있는 하나**를 완벽하게 구현합니다.

- [ ] **제스처 트리거**:
    - 웹캠으로 특정 동작(예: 손들기, 손하트) 인식 시 게임 내 이펙트 발동.
    - *또는*
    - **욕설 탐지 (Unsmile)**: 음성 채팅 중 욕설 감지 시 캐릭터에 'X' 마크 표시.
    - *(둘 중 하나를 선택하여 집중 구현 권장)*

## 6. 🏆 결과 (Result)
- [ ] **게임 종료**: 목표 지점 도달 시 게임 끝.
- [ ] **순위 표시**: 누가 1등인지 표시.
- [ ] **로비로 돌아가기**: 재시작 버튼.
