### 논의된 주요 아이디어

### 1. 실시간 IDE 공유 시스템

- 수업이나 협업 시 실시간으로 코드를 공유하고 동기화하는 기능
- 개발 페이지의 특정 부분을 선택적으로 보여줄 수 있는 기능
- [Socket.io](http://Socket.io)를 활용한 실시간 네트워크 통신 구현 필요
- WebRTC와 유사한 방식으로 구현 가능할 것으로 예상
- 드래그 기능을 통한 코드 공유도 고려 중

### 2. AI 사회자 게임 시스템

- AI가 사회자 역할을 하며 마피아 게임과 같은 다인 참여 게임 진행
- 3D 모델링을 활용하여 AI를 하나의 캐릭터로 시각화
- 방송 형식으로 게임 화면 구성
- 여러 명이 모여야 하는 게임들에 적합
- 온라인 마피아 게임의 장점 활용: 밤 시간에 마피아끼리, 죽은 사람끼리 별도로 대화 가능
- 세션을 나눠서 특정 그룹끼리만 소리를 들을 수 있게 구현

### 3. 모션 인식 게임

- Fall Guys 스타일의 게임을 실제 사람의 움직임으로 플레이
- 카메라를 통한 모션 인식 활용
- VR을 카메라 인식으로 옮겨놓은 느낌
- 팔, 다리 등 기본적인 신체 인식은 가능하나 손가락 단위 인식은 어려울 것으로 예상
- 장비 없이 인식률로 모션캡처하는 것은 어려울 수 있음

### 4. 협동 리듬게임

- 여러 명이 함께 참여하는 리듬게임
- 캐치마인드 스타일로 키워드에 맞는 자세를 취하고 AI가 평가
- 4개 화면으로 분할하여 각 참여자의 모습을 보여주는 방식
- 모션 인식을 활용한 리듬게임 구현

- 실시간 코드 동기화 및 공유
