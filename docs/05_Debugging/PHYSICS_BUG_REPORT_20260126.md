# [디버깅 보고서] 캐릭터 사망 시 물리 엔진 가속 및 프레임 이상 현상 (2026-01-26)

## 1. 문제 현상
- 플레이어 사망 후 씬 재시작 시 이동 속도 및 점프 속도가 누적되어 빨라지는 현상.
- 프레임이 가속되는 느낌과 함께 조작이 불가능할 정도로 속도가 증가함.

## 2. 근본 원인 분석
1. **익명 물리 바디 누수 (Anonymous Body Leak)**:
   - `BaseGameScene.ts`에서 바닥(ground)과 낙사구역(death-zone) 생성 시 변수에 할당하지 않고 생성만 함.
   - `scene.restart()` 호출 시 `resetState()`에서 이를 제거하지 못해, 재시작마다 물리 바디가 맵에 겹겹이 쌓임.
   - 중복된 물리 충돌체들이 엔진의 시간 계산(Delta Time)에 영향을 주거나 중복 연산을 발생시킴.

2. **물리 업데이트 중복 (Step Duplication)**:
   - `autoUpdate: false` 상태에서 수동 `step()`을 호출하고 있으나, 씬 전환 과정에서 설정이 유지되지 않거나 루프가 겹쳐 한 프레임에 다수의 물리 업데이트가 발생함.

## 3. 수정 사항
- **속성 정의**: `groundBody`, `deathZoneBody`를 클래스 멤버로 관리.
- **파괴 로직 보강**: `resetState()`에서 이전 씬의 물리 바디를 `this.matter.world.remove()`로 명시적 제거.
- **진단 시스템**: `PHYSICS_DIAG` 로그를 도입하여 `Body Count`와 `AutoUpdate` 상태 실시간 감시 및 비정상 상태 강제 교정.

## 4. 결과
- 재시작 후에도 물리 객체 수가 일정하게 유지됨(예: 플레이어 수 + 기믹 수 + 기본 바닥 2개).
- 가속 현상 해결 및 일정한 프레임 유지.
