# ✌️ V-Sing 제스처 최적화 보고서 (README_VSING)

본 문서는 V-Sing (브이 사인) 제스처 인식 성능을 개선하기 위해 적용된 최적화 전후 비교 내용을 기술합니다.

## 📁 파일 구조 및 위치
- **프로젝트**: `echoforest-ai`
- **대상 모듈**: Motion Recognition (MediaPipe 기반)

## 📊 최적화 비교 (Before vs After)

| 비교 항목 | 최적화 전 (Before) | 최적화 후 (After) |
| :--- | :--- | :--- |
| **거리 계산 방식** | 픽셀(Pixel) 단위 절대 거리 사용 | **손바닥 크기 기준 정규화(Normalized) 거리** 사용 |
| **엄지 인식 로직** | 단순 펴짐/굽힘 Boolean 체크 | **엄지 끝 ↔ 검지 끝/손목 간의 거리**를 정밀 분석 |
| **손가락 관계 분석** | 각 손가락의 상태만 독립적으로 확인 | **5x5 손가락 끝 거리 매트릭스** 도입 (상대적 위치 분석) |
| **V-Sing 판별 조건** | `검지 펴짐` AND `중지 펴짐` | `검지 펴짐` AND `중지 펴짐` AND **`검지-중지 거리 > 0.18`** |
| **취약점 (한계)** | 카메라 거리 변화에 민감, 손 크기 영향 큼 | **거리/손 크기 불변성 확보**, L제스처/숫자2 오인식 해결 |

## 🛠️ 상세 개선 내용

### 1. 정규화 (Normalization) 적용
기존에는 카메라와의 거리가 멀어지면 좌표 간 거리가 줄어들어 인식이 실패했습니다. 이를 해결하기 위해 **손바닥 크기(Wrist ↔ Middle Finger MCP)**를 기준으로 모든 거리를 나눴습니다.
> `Normalized Distance = Absolute Distance / Palm Size`

### 2. 5x5 Finger Distance Matrix 도입
단순히 손가락이 펴졌는지(Extension)만 보는 것이 아니라, **모든 손가락 끝점 간의 상호 거리**를 계산하여 매트릭스로 관리합니다.
- 예: 검지와 중지가 펴져 있어도, 둘 사이의 거리가 가까우면 V-Sing이 아닌 '숫자 2'로 인식하도록 보정

### 3. 엄지(Thumb) 정밀 판단
엄지는 자유도가 높아 단순 펴짐 체크로 파악하기 어렵습니다.
- **Before**: MCP와 Tip의 Y좌표 비교 등 단순 방식
- **After**: 엄지 끝이 '검지 MCP'나 '손목'으로부터 일정 비율 이상 멀어져야만 펴진 것으로 간주

### 4. 엄격한 V-Sing 임계값 튜닝
- **V-Condition**: 검지와 중지 사이의 정규화 거리가 `0.18` 이상일 때만 V-Sing으로 인정하여 정확도 향상
