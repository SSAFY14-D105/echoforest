# EchoForest AI - 부정 발언 탐지 시스템

> 🎮 협동 게임 "메아리 숲"의 핵심 AI 시스템  
> 부정적 발언을 실시간으로 탐지하여 게임 내 저주를 발동시키는 감정 분석 API

## 🎯 프로젝트 개요

**EchoForest**는 협동 게임에서 플레이어의 음성/채팅을 분석하여 부정적 발언이 감지되면 **저주 패널티**를 부여하는 시스템입니다.

### 게임 컨셉
```
플레이어 발화 → AI 분석 → 부정어 감지 → 저주 발동! 🔮
                                           ↓
                              HP 감소, 이동속도 저하, 맵 난이도 상승
```

### 핵심 메커니즘
- **메아리 카운트**: 부정 발언 시 +2 증가, 임계값 도달 시 저주 발동
- **저주 쿨타임**: 저주 발생 후 4초간 메아리 누적 정지
- **저주 해제**: 특정 주문을 외쳐야 저주 해제 가능

---

## 🤖 AI 모델

### Smilegate unSmile 모델
- **모델**: [smilegate-ai/kor_unsmile](https://huggingface.co/smilegate-ai/kor_unsmile)
- **기능**: 한국어 혐오 발언 탐지 및 카테고리 분류
- **분류 카테고리**: 여성/가족, 남성, 성소수자, 인종/국적, 연령, 지역, 종교, 기타 혐오, 악플/욕설

### 테스트 방법론

| 미치겠다 | 27.5% | 부정 | 관용적 표현 |
| 너 왜 그래 | 24.6% | 부정 | 비난조 |

### Threshold 결정: 17.4%

| 후보 Threshold | 장점 | 단점 |
|----------------|------|------|
| 10% | 더 엄격한 탐지 | 과탐지 발생 |
| **17.4%** ✅ | **균형 잡힌 탐지** | - |
| 25% | 관용적 표현 통과 | 약한 욕설 미탐지 |
| 30% | 더 관대 | "멍청이" 같은 욕설 미탐지 |

> **결론**: 게임의 핵심 재미가 "말조심"이므로, 17.4% threshold가 최적.  
> "짜증나", "열받네" 같은 불만 표현도 저주 발동 대상으로 처리하는 것이 게임 기획과 일치함.

## 🎚️ 심각도 단계 시스템

부정어의 심각도를 3단계로 분류하여 **저주 강도**를 차등 적용합니다.

| 단계 | 라벨 | Confidence 범위 | 예시 | 저주 강도 |
|------|------|-----------------|------|-----------|
| **1** | `critical` | 80% 이상 | 씨발(91.8%), 미친놈(87.2%) | 🔴 최강 저주 |
| **2** | `severe` | 50~80% | 짜증나(75.1%), 닥쳐(64%) | 🟠 강한 저주 |
| **3** | `mild` | 17.4~50% | 멍청이(34.6%), 미치겠다(27.5%) | 🟡 약한 저주 |
| **0** | `clean` | 17.4% 미만 | 안녕하세요, 잘했어 | ✅ 정상 |

## 📁 프로젝트 구조

```
echoforest-ai/
├── README.md              # 프로젝트 문서 (현재 파일)
└── inference/
    ├── app/
    │   ├── __init__.py    # 패키지 초기화
    │   ├── main.py        # FastAPI 앱 진입점, CORS 설정, 라우터 등록
    │   ├── model.py       # unSmile 모델 래퍼, threshold 설정 (17.4%)
    │   ├── routes.py      # API 엔드포인트 정의 (/health, /analyze)
    │   └── schemas.py     # Pydantic 요청/응답 스키마 정의
    ├── requirements.txt   # Python 의존성 목록
    └── README.md          # inference 서버 간단 설명
```

### 핵심 파일 상세

| 파일 | 역할 | 핵심 코드 |
|------|------|-----------|
| `main.py` | FastAPI 앱 생성, 서버 시작 시 모델 사전 로드 | `lifespan()`, CORS 미들웨어 |
| `model.py` | unSmile 모델 로드 및 추론, **Threshold 17.4%** 설정 | `UnSmileModel.predict()` |
| `routes.py` | REST API 엔드포인트 정의 | `analyze_sentiment()`, `health_check()` |
| `schemas.py` | 요청/응답 데이터 검증 (Pydantic) | `SentimentRequest`, `SentimentResponse` |
