# EchoForest AI - 모션 인식 튜닝 리포트

> 🎮 협동 게임 "메아리 숲"의 모션 인식(Motion Recognition) 고도화 과정 기록  
> 데이터 수집, 분석, 그리고 로직 튜닝 과정을 상세히 기록합니다.

## 🎯 목표: "오른볼 콕" 제스처 인식률 개선

사용자가 오른손 검지로 자신의 오른쪽 볼을 찌르는 **"오른볼 콕"** 제스처의 인식률을 높이고, 오탐(False Positive)을 줄이는 것이 목표입니다.

---

## 📊 1. 데이터 수집 및 분석

### 1-1. 초기 문제점
- **미러링 이슈**: 웹캠의 좌우 반전(Mirror Mode)으로 인해, 화면상 오른쪽(사용자 왼쪽 볼)과 물리적 오른쪽 볼의 좌표가 혼동됨.
- **오탐 발생**: 손바닥을 펴고 얼굴을 가리기만 해도 "볼콕"으로 인식됨.
- **다양한 스타일 미지원**: 손가락을 꼿꼿이 펴지 않고 살짝 구부려서 찌르는("귀여운 콕") 동작이 인식되지 않음.

### 1-2. 수집 데이터셋
튜닝을 위해 상황별 랜드마크 데이터를 수집했습니다. (`echoforest-ai/motion-model-test/captures/`)

| 파일명 | 상황 | 주요 특징 (정규화 거리) |
|--------|------|-------------------------|
| `왼볼콕_오른볼콕.csv` | 정석 자세 | 볼-검지 거리 < 0.2, 검지 펴짐(>1.6) |
| `왼볼_오른볼_구부린콕.csv` | 구부린 자세 | 볼-검지 거리 < 0.15, 검지 덜 펴짐(<1.2) |

---

## 🛠 2. 튜닝 과정 및 로직 개선

### 2-1. 좌표계 보정 (Mirroring Calibration)
웹캠 화면은 거울처럼 동작하므로, 사용자가 **오른손**을 들어 **오른쪽 볼**을 찌르면 화면상에서는 **오른쪽**에 나타납니다.
MediaPipe 랜드마크 기준으로는 **반대쪽(왼쪽) 얼굴 좌표**를 사용해야 올바르게 매칭됩니다.

- **AS-IS**: Face Landmark 411번(오른쪽 볼) 사용 → 거리 멀어짐, 인식 불가
- **TO-BE**: Face Landmark **187번(왼쪽 볼)** 사용 → 화면상 오른쪽 위치와 일치, 인식 성공

```javascript
// js/gestures/RightPokeGesture.js
this.cheekPoints = [187, 147, 116, 123, 50]; // 화면상 오른쪽(사용자 왼쪽 얼굴) 타겟
```

### 2-2. 손 모양 필터링 (False Positive 방지)
"손바닥 펴기"와 "볼콕"을 구분하기 위해 **엄지와 중지 사이의 거리**를 분석했습니다.

- **분석 결과**:
  - 손바닥 펴기: 엄지(4) - 중지PIP(10) 거리가 멂 (정규화 거리 > 0.4)
  - 주먹 쥐고 콕: 엄지(4) - 중지PIP(10) 거리가 가까움 (정규화 거리 < 0.35)

- **적용 로직**:
```javascript
// 엄지가 중지 위에 올라가 있어야 함 (주먹 쥔 형태)
const d4to10 = this.distance(hand[4], hand[10]);
if (d4to10 / palmSize > 0.35) return false;
```

### 2-3. "귀여운 콕" 지원 (Hybrid Threshold)
데이터 분석 결과, 검지를 살짝 구부린 자세는 펴짐 정도는 낮지만 **볼과의 밀착도**가 높았습니다. 이를 반영하여 **이원화된 판정 로직**을 도입했습니다.

| 케이스 | 검지 펴짐 (Extension) | 볼과의 거리 (Distance) | 설명 |
|--------|----------------------|-----------------------|------|
| **Case A: 정석 콕** | **> 1.2** (완전 펴짐) | **< 0.3** (여유 있음) | 멀리서 톡 쳐도 인식 |
| **Case B: 구부린 콕** | **> 0.8** (살짝 구부림) | **< 0.2** (매우 가까움) | 확실히 찔러야 인식 |

## 🧪 3. 최종 성능 및 검증

### 개선 결과
- **정확도**: 미러링 보정으로 기본 인식률 **0% → 100%** 개선
- **안전성**: 손바닥 펴기 등 오동작 필터링 적용
- **사용성**: 손가락을 살짝 구부리는 자연스러운 동작도 지원

### 테스트 방법
1. `echoforest-ai/motion-model-test/index.html` 실행
2. 카메라 권한 허용
3. 오른손 검지를 펴서 화면상 오른쪽(자신의 오른쪽 볼) 찌르기
   - ✅ 정석으로 찌르기
   - ✅ 살짝 구부려서 귀엽게 찌르기
   - ❌ 손바닥 펴고 얼굴 가리기 (인식 안 되어야 함)
