# 🧪 EchoForest Heart Lab (Two Hands)

본 저장소는 **양손 하트(Heart) 제스처**를 정밀하게 인식하기 위한 R&D 실험실입니다.

## 🏗️ 하트 인식 아키텍처

V-Sign과 동일한 모듈형 구조를 사용하되, **멀티 핸드(Multi-hand)** 환경에 최적화되었습니다.

1.  **`GestureManager.js`**: `numHands: 2` 설정을 통해 두 손의 랜드마크를 모두 수집하여 `HeartGesture`에 전달합니다.
2.  **`HeartGesture.js`**: 두 손의 상호작용(엄지 끝과 검지 끝의 거리)을 분석합니다.

## ❤️ 하트 인식 원리

### 1. 듀얼 핸드 접점 분석
하트 모양을 형성하는 두 손의 핵심 포인트를 추적합니다.
- **엄지 접점**: 왼쪽 엄지 TIP(4)과 오른쪽 엄지 TIP(4)의 거리 측정
- **검지 접점**: 왼쪽 검지 TIP(8)과 오른쪽 검지 TIP(8)의 거리 측정

### 2. 거리 정규화 (Normalization)
- 카메라와의 거리에 상관없이 인식되도록, 첫 번째 손의 **손바닥 크기(Palm Size)**를 기준으로 모든 임계값을 정규화합니다.

### 3. 방향성 체크 (Alignment)
- 두 손이 엇갈리지 않고 올바른 위치(왼손이 왼쪽, 오른손이 오른쪽)에 있을 때만 하트로 인정하여 오인식을 최소화합니다.

---

## 🚀 사용 방법
1. VS Code **Live Server**로 `index.html` 실행
2. **1️⃣ 모델 로딩** 클릭 (두 손 인식을 위해 약간 시간이 걸릴 수 있습니다)
3. **2️⃣ 카메라 권한** 허용
4. **3️⃣ 감지 시작** 클릭
5. 양손 엄지와 검지를 모아 하트 모양을 만드세요! ❤️
